# أثير — إدارة الموقع

موقع أثير العام بقي بنفس تصميمه، وأضيفت له لوحة تحكم منفصلة في `/admin/`.

## تفعيل Supabase

1. افتح **Supabase SQL Editor** وشغّل الملف `supabase/schema.sql` كاملاً.
2. من **Authentication → Users** أنشئ مستخدمًا بالبريد وكلمة المرور التي ستستخدمها للدخول.
3. انسخ معرّف المستخدم UUID، ثم شغّل هذا الاستعلام في SQL Editor:

   ```sql
   insert into public.admin_users (user_id)
   values ('ضع-معرّف-المستخدم-هنا');
   ```

4. افتح `/admin/` وسجّل الدخول.

املأ `admin/config.js` في بيئة التشغيل برابط Supabase ومفتاح Supabase العام المخصص للمتصفح (anon/publishable key). لا تضع مفتاح `service_role` أو Personal Access Token في هذا الملف أو في أي ملف يصل إلى المتصفح؛ سياسات RLS في `schema.sql` تحمي البيانات وتسمح بالإدارة لأعضاء `admin_users` فقط.

## ما يمكن إدارته

- المنتجات النسائية والرجالية كاملة، مع التعديل والإخفاء والاسترجاع.
- الصور الحالية والجديدة عبر Supabase Storage، مع الإخفاء والاسترجاع.
- النصوص الرئيسية في الصفحة من غير تغيير التصميم.
- رقم واتساب وسعر الباقة ونص التوصيل.

إذا لم تكن جداول Supabase جاهزة، يستمر الموقع العام بالعمل من الملفات الثابتة الحالية كخطة احتياط.
